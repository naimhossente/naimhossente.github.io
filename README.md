# Md. Naim Hossen — Personal Portfolio

A modern, responsive portfolio website for GitHub Pages.

## Publish on GitHub Pages

1. Create a new public repository named exactly `naimhossente.github.io`.
2. Upload all files from this folder, keeping the `assets` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. After deployment, visit: https://naimhossente.github.io/

## SEO

The site includes:
- Descriptive title and meta description
- Canonical URL
- Open Graph metadata
- `ProfilePage` + `Person` JSON-LD structured data
- `robots.txt`
- `sitemap.xml`
- Mobile responsive design

After publishing, submit `https://naimhossente.github.io/sitemap.xml` in Google Search Console and Bing Webmaster Tools.
